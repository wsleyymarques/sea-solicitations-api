# Mission: Dominar backend Spring Boot construindo o desafio SEA

## Why

Construir e entregar o desafio tecnico da vaga de backend com dominio suficiente para explicar, defender e comparar as decisoes durante a avaliacao com a equipe.

## Success looks like

- Implementar os fluxos obrigatorios da API com Java 21 e Spring Boot.
- Executar o ambiente completo com PostgreSQL, Elasticsearch e Docker Compose.
- Testar regras de dominio, autorizacao, persistencia, busca e integracao.
- Explicar com palavras proprias o fluxo entre dominio, casos de uso, portas e adapters.
- Justificar escolhas sobre JWT, JPA, Elasticsearch, outbox, AOP e concorrencia.

## Constraints

- Aprendizado guiado e gradual, sem calendario fixo.
- O aluno escreve a implementacao principal por padrao e pode pedir `implemente direto` na tarefa atual.
- Cada tarefa deve produzir um resultado pequeno, verificavel e relacionado ao projeto real.
- Java 21, Spring Boot e os requisitos do desafio devem ser preservados.

## Out of scope

- Adicionar tecnologias da vaga sem necessidade no desafio.
- Transformar o projeto em microsservicos.
- Criar dominios extras como pagamentos, anexos ou notificacoes.
- Decorar codigo sem compreender as responsabilidades e os trade-offs.
