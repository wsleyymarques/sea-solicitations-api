# Backend Spring Boot no desafio SEA — Resources

## Knowledge

- [Contexto de dominio local](CONTEXT.md)
  Define a linguagem do projeto. Usar ao nomear usuarios, solicitacoes, etapas, cobertura e decisoes.
- [Desenho do roteiro de estudo](docs/superpowers/specs/2026-10-28-study-implementation-roadmap-design.md)
  Define objetivos, limites, marcos e criterios de conclusao da jornada.
- [Spring Boot 3.5: Externalized Configuration](https://docs.spring.io/spring-boot/3.5/reference/features/external-config.html)
  Fonte oficial para `.env`, `spring.config.import`, variaveis de ambiente e precedencia de configuracao.
- [Spring Security: OAuth 2.0 Resource Server JWT](https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html)
  Fonte oficial para validacao de JWT Bearer e protecao dos endpoints.
- [Docker Docs: variaveis e interpolacao no Compose](https://docs.docker.com/compose/how-tos/environment-variables/variable-interpolation/)
  Fonte oficial para `.env`, valores obrigatorios, defaults e `docker compose config`.
- [Spring Boot: REST Clients](https://docs.spring.io/spring-boot/reference/io/rest-client.html)
  Fonte oficial para o `RestClient.Builder` auto-configurado usado pelo adapter sincrono.
- [ViaCEP](https://viacep.com.br/)
  Contrato oficial do endpoint de CEP, incluindo CEP inexistente com `erro=true`.
